Sharplint **0.2.0-prealpha.2** fixes the package README rendering on NuGet.org.

- Display the logo and linked badges using standard Markdown images.
- Present source-build instructions as Markdown.
- Check packaged READMEs for raw HTML outside code examples before publishing.

Install or update with the .NET 10 SDK:

```sh
dotnet tool update --global sharplint --version 0.2.0-prealpha.2
```

For a first installation, use `dotnet tool install --global sharplint --version 0.2.0-prealpha.2`.

See the [README](https://github.com/adrian13579/sharplint#readme) for setup and usage.
