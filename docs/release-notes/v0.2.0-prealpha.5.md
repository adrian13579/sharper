# v0.2.0-prealpha.5

Adds TypeScript/JavaScript syntax and type diagnostics and native configured ESLint rules to the existing MCP tools. C# support continues through Roslyn. Sessions stay warm between requests. Current usage automatically selects the required language services; see [navigation and feedback](../code-navigation.md).

Node.js and servers are installed separately; local ESLint, plugins and config belong to the target project. CLI/setup accept `--typescript-server`, `--eslint-server` and `--node`. Sharper never installs dependencies or applies fixes. node_modules is now excluded from reconciliation for every language service; restart after dependency changes. This remains a pre-alpha document diagnostic connector, not full build/test verification.

Pinned real-server integration tests and Windows/Linux CI cover TypeScript/ESLint and actual MCP. See the service contract and compatibility policy for scope and tested versions. Mutation testing remains stopped at the user's request; previous scores do not establish coverage of these new paths.

Local Windows validation: Debug build has zero warnings/errors; the full coverage run passes 157 tests with zero skips, including 5 real Roslyn and 4 real Node integration tests. Analysis coverage is 96.6% lines, 88.2% branches and 98.4% methods. The isolated installed-package check passes with official Roslyn. Node 24.21.0, .NET SDK 10.0.403/runtime 10.0.14 were used. Linux evidence must come from CI; no new mutation run was performed.
