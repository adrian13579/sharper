# v0.2.0-prealpha.7

Sharper now publishes as a Native AOT tool for Windows x64 and Linux x64. Its native executable does not require an installed .NET runtime. External language servers keep their existing .NET/Node requirements, and installing through NuGet requires the .NET 10 tool installer.

Adds generated JSON metadata for all MCP response models and explicit LSP JSON wire construction. Keeps diagnostics, navigation, optional fields, opaque diagnostic data, cancellation and session behavior. Agent setup supports native executables without Assembly.Location. Debug builds remain managed for tests/coverage.

Packaging changes to a `sharper` pointer and `sharper.win-x64` / `sharper.linux-x64` native packages. Native build/publishing uses each matching OS and uploads both runtime packages before the pointer. No universal managed fallback is shipped. Arbitrary CLR object graphs passed to the public LSP transport must be converted to JsonNode/JsonElement, and custom serialization models need their own metadata.

See native-aot.md for build prerequisites, package commands and verification. This remains pre-alpha; native compilation makes no unmeasured performance or production-readiness claim. Mutation testing remains stopped.

Local Windows validation: Debug and Native AOT builds complete without warnings/errors. The full real-server coverage suite passes 178 tests with zero skips; Analysis coverage is 96.8% lines, 87.7% branches and 98.6% methods. The installed native executable matches its package SHA-256 and passes version/help, agent setup, MCP metadata, real Roslyn diagnostics/navigation, native TypeScript/ESLint diagnostics and TypeScript definition/implementation/reference checks. The benchmark harness builds. Linux native compilation and package checks are configured in CI; they were not run on this Windows host. No new performance measurements or mutation run were performed.
