Historical release **0.2.0-prealpha.3** made MCP the primary diagnostic interface for the connector now named Sharper. It predates the rename and was not republished under the current package identity.

- Select repositories per tool call, including through absolute source paths and compatible MCP client roots.
- Keep up to four repository/solution contexts warm and release the least recently used context when another is needed.
- Configure GitHub Copilot CLI and VS Code while preserving other servers, settings and comments.
- Start MCP stdio through the executable's default mode or `mcp` subcommand.

The standalone `check` and `status` commands were removed. The current renamed MCP tools are documented in the README.

Installation examples from this historical release have been retired. Follow the current README and migration guide for the new package/command identity.

See the [README](https://github.com/adrian13579/sharper#readme) for installation and MCP configuration.
