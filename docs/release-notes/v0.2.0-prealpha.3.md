Sharplint **0.2.0-prealpha.3** makes MCP the primary diagnostic interface for coding agents.

- Select repositories per tool call, including through absolute source paths and compatible MCP client roots.
- Keep up to four repository/solution contexts warm and release the least recently used context when another is needed.
- Configure GitHub Copilot CLI and VS Code with `sharplint setup copilot`, preserving other servers, settings and comments.
- Start MCP stdio with `sharplint` or `sharplint mcp`.

The standalone `check` and `status` commands have been removed. Agents use `sharplint_check` and `sharplint_status` over MCP.

Update and configure your agent:

```sh
dotnet tool update --global sharplint --prerelease
sharplint setup copilot
```

See the [README](https://github.com/adrian13579/sharplint#readme) for installation and MCP configuration.
