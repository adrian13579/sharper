# v0.2.0-prealpha.6

Sharper helps agents write sharper code with deterministic semantic code search and compiler/linter feedback. Adds read-only `sharper_definition`, `sharper_implementation` and `sharper_references` MCP tools for C#, TypeScript and JavaScript, alongside existing diagnostics. References optionally include declarations. Status reports advertised navigation capabilities; unsupported operations are explicit.

Navigation shares session pooling, disk reconciliation, synchronization, deadlines and cancellation with diagnostics. Responses normalize Location/LocationLink ranges, preserve generated/external URIs and deduplicate/order exact findings. Fixes encoded Windows drive URI normalization for navigation and diagnostic locations.

Code manipulation remains agent-owned editing guided by these tools. Rule enforcement comes from native compiler/analyzer/ESLint configuration; verified results cover stable reconciled inputs and supported server requests, not full builds/tests or cross-runtime symbol linkage. See code-navigation.md for scope. The package remains pre-alpha and no mutation run has been resumed.

Local Windows validation: Debug build has zero warnings/errors; the full real-server coverage suite passes 174 tests with zero failures/skips. Analysis coverage is 96.9% lines, 87.6% branches and 98.6% methods. Real Roslyn and TypeScript/JavaScript navigation, actual MCP calls, diagnostics regression and session reuse pass. The isolated installed package passes diagnostic and all three navigation-tool checks with official Roslyn. The benchmark harness builds; no navigation latency/stability measurements or mutation run were performed. Linux validation remains a CI responsibility.
