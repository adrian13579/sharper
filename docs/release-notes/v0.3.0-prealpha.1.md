# v0.3.0-prealpha.1

Migrates the CLI, MCP host, LSP transport, synchronization, evidence normalization, session pool and agent setup to Rust. Language support is profile-driven, rather than a built-in C#/JavaScript/TypeScript list. Multiple configured services can enforce rules on matching files. The same five MCP tools expose feedback, health and optional navigation.

BREAKING CHANGE: explicit LSP profiles replace built-in routing and language-specific provisioning. Per-call backend/solution selectors and legacy server flags are removed. NuGet/.NET builds and distribution are retired in favor of Cargo, native releases and the npm wrapper. See [migration](../migration-to-rust.md) for configuration, boundary and validation changes.

Read-only behavior, UTF-16 positions, deterministic evidence, failures/cancellation and scope limitations remain explicit. This Rust release is pre-alpha and not production-ready. Historical .NET results do not qualify the migration.

Local Windows validation: strict Rust format/Clippy checks, 29 controlled/executable tests, three separately enabled real-server tests, native release MCP checks, official MCP SDK interoperability, installed npm package checks, and five website browser/accessibility tests passed. Linux validation is delegated to CI. Fresh Rust coverage/mutation/performance/soak qualification remains outstanding; mutation testing is stopped.
