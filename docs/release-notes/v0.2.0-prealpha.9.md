# v0.2.0-prealpha.9

Sharper automatically selects language services from the source path. C# uses Roslyn; TypeScript/JavaScript uses TypeScript Language Server, with ESLint feedback where native configuration exists inside the workspace. Navigation selects the semantic server from the source path.

Directory feedback combines applicable language services and preserves individual outcomes and finding provenance. A failed, uncertain or stale language service prevents aggregate completion. Mixed status reports individual warm sessions.

Configuration detection never installs dependencies or substitutes for native server configuration handling. Completed feedback remains scoped document analysis, not build/test verification.

Local Windows validation: all 183 .NET tests pass with zero skips, including actual Roslyn, TypeScript and ESLint integration. Analysis coverage is 96.2% of lines and 87.7% of branches; CLI subprocess routing is exercised separately by MCP tests and is excluded from those coverage figures. Generated C# outputs do not trigger Roslyn during automatic directory discovery. Stryker remains stopped; no mutation score is claimed for this change.

Windows Native AOT packing completes without trim/AOT warnings. Installed NuGet and offline npm packages pass real Roslyn/TypeScript/ESLint diagnostics, automatic combined feedback and status, definition/implementation/reference navigation, warm-session reuse and shutdown checks. Linux validation and complete two-platform npm assembly require CI. Version 0.2.0-prealpha.9 is prepared locally; no tag or registry publication was performed.
