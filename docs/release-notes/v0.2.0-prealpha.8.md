# v0.2.0-prealpha.8

Adds npm/npx distribution as `@adrian13579/sharper`, retaining the sharper command and the existing native MCP tools. The release tarball bundles Windows x64 and Linux x64/glibc executables behind a small Node launcher. Requires Node 22.22.2+; no install scripts, runtime npm dependencies, build steps or install-time binary downloads are needed.

Adds version-stamped packaging from matching NuGet native artifacts, platform/error handling, offline tarball installation checks and shared native CLI/MCP smoke tests for both NuGet and npm. Release CI tests each OS through npm, assembles both binaries into one complete tarball and attaches it to the GitHub release. npm registry publication is opt-in after scope ownership and trusted-publisher configuration; prereleases use the next tag.

C# project/tool version remains the source of truth for all distributions. Existing language service, synchronization, read-only navigation and diagnostic guarantees are unchanged. See npm.md for build and publication setup. This remains pre-alpha; Stryker remains stopped.

Local Windows validation: 178 .NET tests pass with zero skips, all four Node launcher tests pass, and both NuGet and npm installations pass the shared real Roslyn/TypeScript/ESLint MCP smoke checks. The npm tarball installs offline with scripts disabled; shim/version, native hashes, invalid-argument exit codes, agent setup, diagnostics, navigation and shutdown pass. Complete release packaging rejects a missing Linux input without creating a tarball, and partial test bundles remain private. Workflow YAML parses successfully. The complete two-OS bundle and Linux launcher/runtime checks require CI; no Linux binary is fabricated locally. No registry publication or mutation run was performed.
