# v0.2.0-prealpha.13

Adds a configurable custom stdio LSP server profile through `--lsp-config` on MCP launch, guided setup and Codex, Claude Code, OpenCode and Copilot registration. Configure literal process arguments, file extensions, language IDs, initialization options and settings. Sharper automatically includes custom rule feedback alongside native checks and supports new file extensions.

Verified feedback requires standard LSP document-pull diagnostics, document synchronization and stable workspace inputs. Push-only diagnostics do not verify. Optional advertised navigation is available for custom extensions. No arbitrary LSP proxy, edit application, dependency installation or universal server compatibility is implied. Profiles are explicit startup configuration; restart MCP after changes.

See [custom language servers](../custom-language-servers.md). This release remains pre-alpha and is not production-ready.

Validation: the full managed suite passes with real Roslyn/TypeScript/ESLint enabled; the Windows Native AOT NuGet package installs and passes real-server MCP checks. Custom configuration and combined/native feedback are also exercised through the Native AOT host. Custom-server evidence uses a controlled LSP server; third-party compatibility is not implied. Linux validation remains a CI check. Mutation testing remains stopped.
