# v0.2.0-prealpha.12

Updates the original folded-ribbon S and lowercase wordmark to a neutral palette while retaining their dimensional/neomorphic treatment. The README uses a self-contained SVG with light/dark theme styling; charcoal and silver PNG exports remain available. MCP metadata advertises transparent 128 x 128 PNG icons for `light` and `dark` themes, embedded in the native executable without network access. Clients control rendering and theme selection.

Adds a reproducible Chromium export script and checks both embedded icon variants across supported MCP protocol versions. No language-server, diagnostic, navigation or setup behavior changes. Stryker remains stopped; no release tag or registry publication is performed by this change.

Local Windows validation: 43 relevant CLI/branding tests pass with zero skips, including actual MCP metadata for both supported protocol versions. Browser exports were inspected on opaque white and dark-charcoal backgrounds; both 128 x 128 icon variants contain grayscale pixels with identical alpha. Native AOT packing completes without trim/AOT warnings. Installed NuGet and offline npm packages pass themed icon metadata, setup and real Roslyn/TypeScript/ESLint diagnostics/navigation checks. Analysis code is unchanged; its full suite, coverage and mutation runs were not repeated for this branding-only change. Linux runtime checks remain CI qualification.
