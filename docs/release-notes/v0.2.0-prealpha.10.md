# v0.2.0-prealpha.10

Adds `sharper setup codex`, `sharper setup claude` and `sharper setup opencode`. Registrations start the running Sharper executable with no fixed workspace and forward optional native server/Node paths. Copilot setup remains supported.

Codex registration delegates to the installed native Codex CLI with separate command arguments, supports custom executable/home paths, and propagates startup failures, client failures, timeout and cancellation. Claude Code merges user-scoped stdio JSON; OpenCode merges an enabled local command array in JSON/JSONC. Both preserve unrelated settings, validate existing input before writing and support idempotent reruns. Standard configuration-directory environment variables and explicit profile overrides are supported. See [agent setup](../agent-setup.md).

Stryker remains stopped. No tag or registry publication is performed by this change.

Local Windows validation: 196 .NET tests pass with zero skips, including 41 CLI/setup tests and actual Roslyn/TypeScript/ESLint integration. Native Codex registration in a disposable profile preserves an unrelated MCP server and configuration values; its native writer can normalize formatting and table comments. installed Claude Code recognizes the generated registration as user-scoped and connects to Sharper. OpenCode schema/configuration behavior is tested without its client executable, which is not installed locally. Analysis coverage remains 96.2% line / 87.7% branch; CLI subprocess coverage is excluded.

Windows Native AOT packing passes without trim/AOT warnings. Installed NuGet and offline npm packages pass repeated Claude/OpenCode configuration generation, repeated actual Codex CLI registration, metadata/version/help, and real Roslyn/TypeScript/ESLint diagnostic/navigation checks. Linux execution and full two-platform npm assembly remain CI checks.
