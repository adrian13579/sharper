Historical release **0.2.0-prealpha.1** was the first pre-alpha of the connector now named Sharper. It predates the rename; this version was not republished under the current package identity.

- Installable .NET tool.
- MCP stdio tools for document diagnostics and session status.
- CLI checks with readable and JSON output.
- Compiler and analyzer diagnostics from Microsoft's official Roslyn language server.
- Persistent MCP sessions, disk synchronization, and explicit completion and freshness metadata.

Installation commands from this historical release have been retired. Use the current README and migration guide rather than requesting this old version under the new package name.

See the [README](https://github.com/adrian13579/sharper#readme) for MCP configuration and CLI usage, and the [service contract](https://github.com/adrian13579/sharper/blob/main/docs/lsp-service.md) for diagnostic scope and freshness guarantees.
