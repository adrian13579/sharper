Sharplint **0.2.0-prealpha.1** is the first pre-alpha release of the Roslyn diagnostic connector for coding agents.

- Installable .NET tool with the `sharplint` command.
- MCP stdio tools: `sharplint_check` and `sharplint_status`.
- CLI checks with readable and JSON output.
- Compiler and analyzer diagnostics from Microsoft's official Roslyn language server.
- Persistent MCP sessions, disk synchronization, and explicit completion and freshness metadata.

Install with the .NET 10 SDK:

```sh
dotnet tool install --global sharplint --version 0.2.0-prealpha.1
dotnet tool install --global roslyn-language-server --version 5.13.0-1.26514.10
sharplint --version
```

The `.nupkg` attached to this release can also be downloaded and installed with `--add-source /path/to/download/directory`.

See the [README](https://github.com/adrian13579/sharplint#readme) for MCP configuration and CLI usage, and the [service contract](https://github.com/adrian13579/sharplint/blob/main/docs/lsp-service.md) for diagnostic scope and freshness guarantees.
