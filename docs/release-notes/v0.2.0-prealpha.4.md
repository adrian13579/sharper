Sharper **0.2.0-prealpha.4** renames the connector and its public integration points.

- Executable and .NET tool package: `sharper`.
- Solution/projects/namespaces: `Sharper.slnx` and `Sharper.*`.
- MCP identity and tools: `sharper`, `sharper_check` and `sharper_status`.
- Environment variables: `SHARPER_ROSLYN_PATH` and `SHARPER_TEST_ROSLYN`.
- Repository and logo wordmark: `adrian13579/sharper`, with the purple S retained.
- `sharper setup copilot` migrates an existing legacy server entry when a Sharper entry is absent, preserving unrelated JSONC values/comments and custom entry settings. If both entries exist, it updates Sharper and leaves the other entry for review.

This is a breaking rename. See the [migration guide](../migration-to-sharper.md). Existing package releases and recorded measurements retain their original identities; this rename does not republish them or qualify the renamed candidate for production.
